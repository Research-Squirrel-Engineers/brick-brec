Query the graph

There is no SPARQL endpoint and no server. The graph is fetched as a static file (graph.nt: ontology, Wikidata mapping, the four FDOx bundles and the registry pins) and parsed in your browser by rdflib under Pyodide. Edit a query and press Run; nothing you type leaves your machine. The page needs to be served over HTTP (GitHub Pages does this); opened from a local file the browser blocks the fetch.

1. Which LREC classes sit directly under a CRM family class?

Every LREC class is anchored in CIDOC CRM, CRMdig or CRMinf. This lists the direct anchors; classes that reach the family only through another LREC class do not appear here (see the CRM coverage page).
