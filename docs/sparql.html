Query the graph

There is no SPARQL endpoint and no server. The graph is fetched as a static file (graph.nt: ontology, Wikidata mapping, the four FDOx bundles and the registry pins) and parsed in your browser by rdflib under Pyodide. Edit a query and press Run (or Ctrl+Enter); the editor colours the syntax and checks it with the SPARQL parser of rdflib while you type. Nothing you type leaves your machine. The page needs to be served over HTTP (GitHub Pages does this); opened from a local file the browser blocks the fetch.

1. Which BREC classes sit directly under a CRM family class?

Every BREC class is anchored in CIDOC CRM, CRMdig or CRMinf. This lists the direct anchors; classes that reach the family only through another BREC class do not appear here (see the CRM coverage page).

2. Identification hypotheses, ranked by confidence

The confidence is a subjective estimate by the AI assistant, not a measurement. Hypotheses overlap and do not sum to 1.

.rq file

3. Which evidence was used for which identification?

An identification (crminf:I5 Inference Making) uses evidence as a premise and concludes a hypothesis.

.rq file

4. Which beliefs of the AI assistant did a person adopt, and on what evidence?

A belief adoption (crminf:I7) is the act in which a person takes over a belief on the strength of evidence. The belief value (crminf:I6) is the confidence of the AI assistant. A hypothesis without an adoption is still a conjecture.

.rq file

5. Scans: when, with what, how many photos, where

6. The four FDOx: concept DOI, title and pinned version
